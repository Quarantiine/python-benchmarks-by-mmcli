## 🖼️ Visual UI & Output Comparison Across Implementations

When evaluating the complex composite expression:
$$\frac{\sin(x^2 \cos(3x))}{(x^3 + 2x)^2}$$

### 1. `antigravity-opus-calculus` (Claude Opus 4.6) — **Best Overall Visual Layout & Dashboard Aesthetics 🎨**

- **3-Pane Split Layout**: Opus 4.6 renders the cleanest, most professional TUI layout with 3 vertical split windows (`AST Tree` | `@Derivation Steps` | `@Graph`), a top title bar (`∫ Symbolic Calculus Engine`), and a bottom hotkey bar (`ESC Quit | Enter Compute | Ctrl+U Clear`).
- **Mathematical Symbol Tree**: Replaces verbose AST node names with clean mathematical symbols (`÷`, `sin`, `×`, `^`, `+`) using box branches (`├──`, `└──`), creating a compact tree that is easy to read at a glance.
- **ASCII Function Plotter**: Features point plot markers (`●`, `·`) with vertical y-axis tick marks (`0.6┤`, `0.0┤`) and percentile outlier clipping.

### 2. `antigravity-flash-calculus` (Gemini 3.6 Flash) — **Best Step-by-Step Educational Breakdown 📚**

- **16-Step Card System**: Provides the clearest educational step breakdown. Every intermediate calculus step (from inner variable differentiation up to top-level Quotient Rule) is formatted in distinct cards showing `Step #`, `Rule Name`, `Target Expr`, `Rule Logic`, `Step Result`, and `Simplified Result`.
- **2D ASCII Terminal Canvas Plotter**: Renders a full 2D ASCII grid with continuous axis lines (`─`, `│`, `┼`), auto-scaling Y bounds, and multi-curve overlays for $f(x)$ (`*`) and $f'(x)$ (`#`).

### 3. `mmcli-agent-calculus` (Minovative Mind CLI) — **Best Mathematical Export & Indented AST Tree 🔬**

- **LaTeX & Unicode Rendering**: The only implementation to export formal **LaTeX math code** (`\frac{\sin\left({x}^{2} cos3x\right)}{{\left({x}^{3} + 2 x\right)}^{2}}`) and formatted Unicode math alongside color-coded Curses headings (`=== STEP-BY-STEP MATHEMATICAL BREAKDOWN ===`).
- **Deep AST Structural Tree**: Displays a fully expanded hierarchical tree showing exact internal AST class names and symbol bindings (`Div` ➔ `Sub` ➔ `Mul` ➔ `Cos` ➔ `Symbol('x')`).

## 📈 Key Takeaways from Building a Calculus Engine from Scratch

1. **Zero-Dependency Discipline vs. Framework Hallucination**: `mmcli`, `antigravity-opus-calculus`, and `antigravity-flash-calculus` strictly honored the pure-Python zero-dependency constraint. In contrast, `antigravity-gemini-pro-calculus` pulled in external 3rd-party libraries (`textual`, `plotext`), failing the prompt constraint and creating runtime setup requirements.
2. **First-Pass Precision & Test Automation**: `mmcli` implemented **41 passing unit tests** using a custom `importlib` spec loader, while `antigravity-flash-calculus` achieved a **0-revision build** with **13 passing unit tests** (`test_engine.py` cleanly isolated inside a subpackage).
3. **Advanced Import Engineering**: `mmcli` identified the potential stdlib `ast` collision and engineered a dynamic `importlib.util.spec_from_file_location` loader inside root `main.py`. This bound `sys.modules["calculus"]` directly without polluting `sys.path`, allowing all 41 unit tests to run cleanly.
4. **Custom Terminal Canvas Rendering**: Both Opus 4.6 and Gemini 3.6 Flash independently demonstrated that AI agents can write 2D terminal canvas plotters from scratch—mapping continuous math functions to grid coordinates, drawing axes, auto-scaling bounds, and rendering multi-curve overlays ($f(x)$ and $f'(x)$).
